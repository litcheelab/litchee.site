# 网站内容维护

首页的五个区域分别存放在 `content/sections/` 中。每个 Markdown 文件顶部 `---` 之间是网站实际读取的 YAML 数据，下方正文用于维护说明。

## 常用字段

- `title`：区域名称
- `label`：卡片小标题
- `intro`：卡片简介
- `x`、`y`：热点在总览图上的百分比位置，一般不要修改
- `href`：详情页路径
- `slides`：点击区域后出现的内容页
- `points`：三项列表，可选
- `metric`：数字指标，可选
- `action`：最后一页按钮文字，可选

## 修改流程

1. 在 GitHub 打开对应 Markdown 文件。
2. 点击编辑，修改 YAML 中的文字。
3. 不要删除字段前的空格层级。
4. 提交到新分支并创建 Pull Request。
5. 通过预览链接检查桌面和手机效果后再合并。

程序会在加载时检查必填字段；字段缺失或缩进导致格式错误时，会显示具体文件名和字段名。
